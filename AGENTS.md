# Bluey agent guidance

Bluey is a personal capability repository for Codex. It intentionally has no
multi-agent roles, routing, or orchestration.

Follow the repository documentation before creating or changing a capability:

- [Capability conventions](docs/conventions.md) are the authoritative rules for
  naming, package structure, interface documentation, and MCP safety.
- [Development tooling](docs/development-tooling.md) defines the workspace
  build, test, and validation commands.
- [MCP development notes](docs/mcp-development.md) cover the local development
  and Codex-connection workflow for MCP servers.
