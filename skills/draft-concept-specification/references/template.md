### 数据模型

> 使用 TypeScript 定义概念的数据模型。
> 有限取值必须使用 enum，不能使用字面量类型。
> 除非确有必要，否则避免使用继承。
> 为不能通过名称直接理解的字段添加中文注释。

<!--
格式：

```ts
interface {ConceptName} {
  {property}: {Type};
}
```

示例：

```ts
enum WorkspaceStatus {
  Active = 'active',
  Archived = 'archived'
}

interface Workspace {
  id: string;
  status: WorkspaceStatus;
}
```
-->

### 数据模型案例

> 使用与数据模型一致的标准 JSON 展示代表性业务数据。JSON 代码块内不得包含注释。
> 案例中的字段、类型和取值必须符合关键属性、数据模型与规则约束。
> 数据模型存在变种时，每个变种使用独立的 JSON 代码块，并在代码块前最近的非空行使用加粗的业务名称注释区分。

<!--
格式：

**{变种业务名称}：**

```json
{
  "property": "value"
}
```

示例：

```json
{
  "id": "001",
  "status": "active"
}
```
-->
